Staff Directory & MFA

Learning model – not production security Sign-in here runs entirely in your browser. Anyone using the browser developer tools can read or change localStorage and bypass these checks. In a real system, passwords, MFA codes and roles must be verified and enforced server-side. Hiding a section in the page is not security; this demo only shows the concepts (salted password hashing, TOTP, role-based UI and joiner/leaver steps). See RISKS.md.
