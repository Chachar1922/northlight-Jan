    Run the diagnostic tools (IT staff)

    Two read-only Node.js scripts in the tools folder collect the same information automatically. They never change any setting.

    npm run pc-health        # OS, free disk space, firewall, updates
npm run network-doctor   # connection, IP, router, 1.1.1.1, DNS
    How to read the result
    ResultMeaning
    PASSThe check succeeded.
    FAILThe check failed. For the network doctor, fix the first failing step first; later steps often fail because of it.
    SKIPThe information is not available on this computer (missing tool or permissions). It is not a pass.

    Network doctor steps: 1) connection exists · 2) IP address assigned (169.254.x.x is a failure) · 3) router answers ping · 4) 1.1.1.1 answers ping · 5) a domain name resolves (a failure here with step 4 passing means a DNS problem).
